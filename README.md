# AI & Robotics Career Exploration

AI Application과 Physical AI 분야를 직접 구현하고 실험하며, 나에게 맞는 개발 방향을 탐색하는 프로젝트입니다.

## Motivation

어릴 때부터 상상한 것을 실제로 구현해 사람들에게 도움이 되는 결과물을 만드는 일에 관심이 있었습니다. 기술을 통해 사람들에게 편의와 행복을 전하고, 시간과 공간의 제약을 넘어 도움을 줄 수 있다는 점이 개발에 끌렸던 근본적인 이유입니다.

대학교 3학년 때는 사람들에게 가까이 있는 서비스를 만들면서 시각적인 요소도 다룰 수 있는 웹 개발을 선택했습니다. 특히 프론트엔드 개발은 내가 만든 결과물을 눈으로 확인하고, 사용자가 서비스를 이용하는 경험을 구체적으로 만들어 갈 수 있다는 점에서 흥미로웠습니다. 이후 웹 개발 프로젝트와 AI 프로젝트를 경험하며 사용자에게 필요한 기능을 구현하고, 모델과 데이터를 다루는 과정도 배웠습니다.

한편, 이전부터 《인터스텔라》의 타스나 《빅 히어로》의 베이맥스처럼 사람과 친근하게 소통하고 실제 환경에서 사람을 돕는 로봇에도 관심이 있었습니다. 사람의 말과 의도를 이해하는 것을 넘어, 주변 환경을 인식하고 상황에 맞게 판단하며 실제 행동으로 도움을 주는 기술을 직접 경험해 보고 싶었습니다. 하지만 당시에는 관련 분야를 직접 접할 기회가 적었고, 진입장벽도 높게 느껴져 쉽게 도전하지 못했습니다.

AI의 발전으로 개발 환경이 빠르게 변화하는 지금, 이전에는 어렵게 느꼈던 AI와 로보틱스 분야를 작은 프로젝트부터 탐색해 볼 기회가 생겼다고 생각합니다. 내가 기술을 통해 이루고 싶은 목표가 웹이라는 특정 기술에 한정되어 있지 않다면, 앞으로의 가능성 역시 기존의 경험에만 가두어 둘 필요는 없다고 느꼈습니다.

따라서 이 프로젝트에서는 AI Application과 컴퓨터 비전 프로젝트를 직접 구현하고 실험하며, 각 분야에서 어떤 문제에 흥미를 느끼는지 알아보고자 합니다. 결과가 예상과 다를 때 원인을 분석하고 개선하는 과정까지 경험하면서, 내가 어떤 기술과 문제 해결 방식에 더 몰입하는지 구체적으로 확인하는 것이 목표입니다.

처음부터 진로를 확정하거나 모든 것을 알고 시작하기보다, 작은 시도를 통해 나의 흥미와 가능성을 발견해 나가고자 합니다.

## Projects

### Project A. RAG-based Document Q&A

**분야:** AI Application

문서를 검색하고 관련 정보를 바탕으로 답변하는 질의응답 시스템을 구현합니다.

- 문서 검색과 검색 결과의 관련성 확인
- 답변이 문서의 근거를 충실히 반영하는지 평가
- 오답과 검색 실패의 원인 분석
- 검색 방식과 프롬프트 개선 전후 비교

### Project B. Real-time Object Tracking

**분야:** Computer Vision / Robotics Exploration

Mac의 내장 카메라와 OpenCV를 활용해 특정 색상의 물체를 실시간으로 탐지하고 추적합니다.

- 색상 기반 물체 탐지 구현
- 조명, 배경, 거리와 물체 이동에 따른 성능 관찰
- 탐지 임계값과 영상 처리 방식 개선
- 프레임 간 추적 안정성 및 실패 사례 분석

이 프로젝트는 Physical AI 전체를 구현하는 프로젝트가 아니라, 로봇 인지와 연결되는 컴퓨터 비전의 기초를 탐색하기 위한 실험입니다.

## How I Work

1. 최소 기능을 먼저 구현합니다.
2. 다양한 조건에서 직접 실행하고 실패 사례를 수집합니다.
3. 실패 원인에 대한 가설을 세웁니다.
4. 변수를 하나씩 바꾸어 실험하고 결과를 비교합니다.
5. 결과와 한계를 기록하고 다음 개선 방향을 정합니다.

## What I Want to Learn

- 어떤 문제를 해결할 때 가장 큰 흥미를 느끼는가?
- 결과가 예상과 다를 때 어떤 방식의 디버깅을 더 즐기는가?
- 데이터와 모델을 개선하는 일과 실제 환경의 변수를 다루는 일 중 어느 쪽에 더 끌리는가?
- 다음 단계에서 어떤 기술을 더 깊게 공부하고 싶은가?

## Notes

실험 결과뿐 아니라 실패 사례, 가설, 개선 과정도 함께 기록합니다. 완성된 결과물만 보여 주기보다 문제를 이해하고 해결해 가는 과정을 남기는 것이 목표입니다.

## How I Use ChatGPT

이 프로젝트는 ChatGPT를 활용해 AI Application과 Computer Vision 분야를 탐색하고, 구현부터 실험 및 회고까지의 과정을 기록하는 프로젝트입니다.

ChatGPT를 단순한 코드 생성 도구가 아니라 학습 파트너이자 실험 기록 보조 도구로 활용합니다. 다만 AI가 제안한 해결책을 그대로 채택하기보다, 직접 실행하고 결과를 확인한 뒤 적용 여부를 판단합니다.

### Areas of Use

- **탐색 및 학습:** 분야별 핵심 개념을 이해하고, 프로젝트 범위와 구현 단계를 구체화합니다.
- **구현 지원:** 코드 구조와 라이브러리 사용법을 파악하고, 오류의 원인과 해결 방법을 탐색합니다.
- **실험 설계:** 실패 사례를 바탕으로 원인에 대한 가설을 세우고, 비교할 조건과 개선 방법을 정리합니다.
- **결과 분석:** 실험 결과와 예상의 차이를 검토하고, 추가 검증이 필요한 부분을 찾습니다.
- **문서화 및 회고:** 구현 과정, 실험 조건, 결과, 한계와 다음 개선 방향을 정리하고 진로 탐색 과정에서 얻은 인사이트를 기록합니다.

### Principles

1. AI의 설명이나 코드가 올바르다고 가정하지 않고 직접 실행하고 검증합니다.
2. 중요한 기술적 선택은 선택 이유와 트레이드오프를 이해한 뒤 결정합니다.
3. 실험 결과와 해석을 구분하고, 검증하지 않은 내용을 사실처럼 기록하지 않습니다.
4. ChatGPT가 제안한 내용과 직접 수행·검증한 내용을 구분해 기록합니다.
5. 프로젝트가 진행되면서 ChatGPT를 활용한 범위와 방식도 함께 기록하고, AI 활용이 문제 해결에 실제로 어떤 도움을 주었는지 돌아봅니다.

### Transparency

프로젝트별 README와 실험 로그에 필요에 따라 ChatGPT 활용 내역을 기록합니다. 여기에는 활용 목적, 주요 제안, 직접 수행한 검증, 최종적으로 채택하거나 수정한 판단이 포함됩니다.

목표는 AI의 도움으로 결과물을 빠르게 만드는 데 그치지 않고, AI를 활용하면서도 문제를 이해하고 검증하며 독립적으로 판단하는 역량을 기르는 것입니다.
