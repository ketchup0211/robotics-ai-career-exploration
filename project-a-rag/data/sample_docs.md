# 실험용 문서: 가상의 로봇 도우미

## 문서 1: 로봇의 기능

로봇 도우미 루미는 음성 명령을 받아 사용자의 요청을 처리한다. 사용자가 길을 물으면 현재 위치와 목적지를 확인하고 이동 경로를 안내한다.

## 문서 2: 주변 환경 인식

루미는 카메라 센서로 주변의 물체를 인식한다. 장애물이 감지되면 충돌을 피하기 위해 이동 경로를 변경한다.

## 문서 3: 사용자 지원

루미는 사용자의 요청에 따라 필요한 정보를 제공한다. 요청의 의미가 불분명하면 추가 질문을 통해 의도를 확인한다.

## 문서 4: 한계와 안전

루미는 센서 데이터가 불확실하거나 필요한 정보를 얻지 못하면 상황을 확정적으로 판단하지 않는다. 안전이 중요한 상황에서는 무리하게 이동하지 않고 사용자에게 확인을 요청한다.
