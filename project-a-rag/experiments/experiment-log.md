## EXP-01: Baseline Retrieval

- **상태:** 1차 기준선 테스트 완료
- **실험 날짜:** 2026-10-29
- **목적:** 작은 문서 모음에서 질문과 관련된 문서 조각을 검색할 수 있는 가장 단순한 기준선을 만든다.
- **초기 가설:** 문서가 작고 질문에 핵심 키워드가 포함되어 있다면, 키워드 기반 검색만으로도 일부 질문의 관련 근거를 찾을 수 있을 것이다.
- **환경 및 데이터:** Python 3.10.13, `project-a-rag/data/sample_docs.md`의 가상 로봇 도우미 문서
- **변경한 변수:** 최초 기준선 구현. 질문과 문서의 중복 단어 수를 점수로 사용한다.
- **ChatGPT의 제안:** 간단한 키워드 검색기를 먼저 구현하고, 실행 후 실제 결과를 확인한다.
- **직접 수행한 작업:** `project-a-rag/src/retriever.py`를 실행하고 세 가지 질문으로 검색 결과를 확인했다. 이후 현재 진행 상황을 GitHub에 push했다.
- **관찰한 결과:**
  - 질문 `장애물이 감지되면 어떻게 해?`: 문서 2가 점수 2로 검색되어 관련 정보를 찾았다.
  - 질문 `사용자의 의도를 확인하는 방법은?`: 관련 문서 3이 점수 2로 1위에 검색됐다. 문서 1도 점수 1로 함께 검색되어 관련성이 낮은 결과가 포함됐다.
  - 질문 `오늘 서울 날씨는 어때?`: 일치하는 단어가 있는 문서를 찾지 못했다.
- **예상과 달랐던 점:** 표현이 다른 질문에서도 관련 문서가 상위에 나왔지만, 두 번째 질문에서는 관련성이 낮은 문서도 함께 나왔다.
- **해석 및 한계:** 키워드 중복 점수는 간단한 질문에서 유용한 기준선이 된다. 다만 점수가 낮은 결과가 질문과 실제로 관련 있다는 보장은 없다. 문서에 답이 없는 질문에서 검색 결과가 나오지 않은 것은 이 테스트 데이터와 질문에 한정된 관찰이며, 모든 경우에 답변 불가를 정확히 판별한다는 뜻은 아니다.
- **다음 단계:** 관련 문서가 1위인 것은 유지하면서 불필요한 추가 결과를 줄일 수 있는지, 상위 결과만 표시하는 방식으로 비교한다. 이는 검색 품질 개선 실험이며, 아직 결과는 없다.

## EXP-02: 질문 표현에 따른 검색 결과 확인

- **상태:** 1차 테스트 완료
- **실험 날짜:** 2026-10-29
- **목적:** 질문 표현에 따라 관련 문서를 찾는지, 문서에 없는 질문을 구분하는지 확인한다.
- **초기 가설:** 질문과 문서의 단어가 겹치면 관련 문서를 찾을 수 있지만, 표현이 달라지면 검색 결과가 부정확해질 수 있다.
- **환경 및 데이터:** Python 3.10.13, `project-a-rag/data/sample_docs.md`의 가상 로봇 도우미 문서
- **변경한 변수:** 질문 표현을 변경하고, 문서에 없는 질문을 추가했다.
- **ChatGPT의 제안:** 서로 다른 세 가지 질문으로 검색 결과를 확인하고, 결과에 따라 검색기의 한계를 분석한다.
- **직접 수행한 작업:** `retriever.py`를 실행해 세 가지 질문을 입력하고 실제 출력 결과를 확인했다.
- **관찰한 결과:**
  - `루미는 장애물을 어떻게 감지해?`: 처음에는 문서 1이 점수 1로 선택됐다. 장애물 감지에 관한 정보가 있는 문서 2를 찾지 못했다.
  - `루미는 사용자의 의도가 불분명하면 어떻게 해?`: 문서 3이 점수 3으로 선택됐고, 관련 정보를 포함하고 있었다.
  - `오늘 서울 날씨는 어때?`: 관련 근거를 찾지 못했다는 메시지를 출력했다.
  - 추가 진단으로 상위 3개 결과를 출력하자 문서 1, 2, 3이 모두 점수 1로 나왔다.
- **예상과 달랐던 점:** 장애물 감지에 관한 질문에서 관련 문서보다 관련성이 낮은 문서가 선택됐다. 상위 결과를 확인한 결과 세 문서의 점수가 모두 같았고, 문서 1이 먼저 표시됐다.
- **해석 및 한계:** 현재 검색기는 질문과 문서에 공통으로 등장하는 고유 단어의 개수를 기준으로 순위를 결정한다. 질문의 핵심 표현인 '장애물'과 '감지해'가 관련 문서의 표현과 일치하지 않아 관련 문서의 점수가 높아지지 않았다. 모든 문서에 공통으로 있는 '루미' 같은 단어가 점수에 기여할 수 있고, 점수가 같으면 원래 문서 순서가 유지되어 첫 번째 문서가 앞에 나올 수 있다. 문서에 없는 질문에서 검색 실패를 반환했지만, 모든 질문에서 답변 불가를 올바르게 판단하는지는 추가 검증이 필요하다.
- **다음 단계:** 단순히 상위 문서를 출력하는 대신, 검색 점수를 개선할 방법을 실험한다. 특히 한국어 어미 변화와 핵심 키워드의 중요도를 고려할 수 있는 방식을 검토하고, 같은 질문으로 개선 전후를 비교한다.

## EXP-03: 간단한 한국어 단어 정규화 적용

- **상태:** 1차 테스트 완료
- **실험 날짜:** 2026-10-29
- **목적:** 질문과 문서의 단어 형태가 달라도 관련 문서를 검색할 수 있도록 간단한 규칙 기반 정규화를 적용한다.
- **초기 가설:** 일부 조사와 어미를 제거하고 공통 단어를 제외하면, 핵심 단어가 일치하는 관련 문서의 점수가 높아질 수 있다.
- **환경 및 데이터:** Python 3.10.13, `project-a-rag/data/sample_docs.md`의 가상 로봇 도우미 문서
- **변경한 변수:** `tokenize()` 함수에 조사·어미 제거 규칙과 불용어 목록을 추가했다. 검색 점수 계산 방식 자체는 유지했다.
- **ChatGPT의 제안:** 외부 라이브러리 없이 규칙 기반으로 단어를 정규화하고, EXP-02에서 실패했던 질문으로 결과를 비교한다.
- **직접 수행한 작업:** `retriever.py`를 실행하고 `루미는 장애물을 어떻게 감지해?`를 입력해 검색 결과를 확인했다.
- **관찰한 결과:** 문서 2(주변 환경 인식)가 점수 2로 검색됐으며, 상위 3개 출력에는 문서 2만 표시됐다.
- **예상과 달랐던 점:** EXP-02에서는 세 문서가 모두 점수 1이었지만, 정규화 규칙 적용 후에는 관련 문서 2의 점수가 2가 되어 검색 결과가 개선됐다.
- **해석 및 한계:** 이 질문에서는 일부 조사·어미 제거와 불용어 처리가 검색에 도움이 됐다. 다만 규칙 기반 방식은 미리 정의한 형태만 처리하므로 새로운 어미, 예외, 문맥에 대응하려면 규칙을 계속 추가해야 한다. 이번 결과는 한 질문에 대한 관찰이므로 다른 표현에서도 효과가 있는지는 추가 검증이 필요하다.
- **다음 단계:** 다른 질문 표현과 실패 사례를 추가해 규칙 기반 정규화의 일반화 한계를 확인한다. 이후 형태소 분석기 또는 의미 기반 검색과 비교할 때 기준선으로 사용한다.

## EXP-04: 질문 표현 변화에 대한 검색 강건성 확인

- **상태:** 1차 테스트 완료
- **실험 날짜:** 2026-10-29
- **목적:** 규칙 기반 정규화 이후에도 의미는 비슷하지만 표현이 다른 질문에서 관련 문서를 검색할 수 있는지 확인한다.
- **초기 가설:** 질문에 문서의 핵심 단어가 직접 포함되면 검색될 가능성이 높지만, 동의어나 의미상 유사한 표현만 사용하면 검색에 실패하거나 관련성이 낮은 문서가 선택될 수 있다.
- **환경 및 데이터:** Python 3.10.13, `project-a-rag/data/sample_docs.md`의 가상 로봇 도우미 문서
- **변경한 변수:** 코드는 변경하지 않고 질문 표현만 바꾸어 테스트했다.
- **ChatGPT의 제안:** 작동 방식, 사용자 지원, 정보 획득 등 의미상 관련된 여러 질문을 입력해 검색 결과를 비교한다.
- **직접 수행한 작업:** `retriever.py`에서 아래 질문들을 직접 실행했다.
- **관찰한 결과:**
  - 질문 `루미에게서 정보 얻기`: 문서 3(사용자 지원)과 문서 4(한계와 안전)가 각각 점수 1로 표시됐다.
  - 질문 `루미의 원리`: 관련 근거를 찾지 못했다.
  - 질문 `루미는 어떻게 작동해?`: 관련 근거를 찾지 못했다.
  - 질문 `루미는 사용자에게 어떤 도움을 줘?`: 문서 1(로봇의 기능), 문서 3(사용자 지원), 문서 4(한계와 안전)가 각각 점수 1로 표시됐다.
  - 질문 `루미의 작동 방식은 무엇이야?`: 관련 근거를 찾지 못했다.
- **예상과 달랐던 점:** 사용자가 의도한 질문 `루미의 원리`와 `루미의 작동 방식은 무엇이야?`는 문서 1의 작동 설명과 관련이 있지만 검색 결과가 나오지 않았다. 반면 `루미는 사용자에게 어떤 도움을 줘?`에서는 관련 문서가 검색됐으나 모든 결과의 점수가 같아 순위를 구분하지 못했다.
- **해석 및 한계:** 현재 검색기는 질문과 문서 사이의 단어 중복만 점수화한다. 불용어 목록에서 `루미`가 제외되고 `원리`나 `작동`이 문서에 있는 표현과 겹치지 않으면 관련 문서를 찾지 못할 수 있다. `도움` 같은 단어가 일부 문서와 겹치더라도 점수만으로 실제 관련성을 구별하지 못한다. 이번 실험은 소규모의 가상 문서 집합에 대한 정성적 테스트이며, 일반적인 검색 성능을 입증하지는 않는다.
- **다음 단계:** 현재 키워드 검색기를 기준선으로 보존하고, 의미가 비슷한 표현을 검색할 수 있는 의미 기반 검색 방법을 조사·실험한다. 개선 전후에는 동일한 질문 집합을 사용해 관련 문서 검색 여부와 순위 변화를 비교한다.
