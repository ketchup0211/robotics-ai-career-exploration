# EXP-07: YOLO 실행 환경 설치

- **날짜:** 2026-11-05
- **상태:** 설치 및 환경 확인 완료. 실시간 추론은 아직 실행하지 않음.
- **목적:** HSV 색상 기반 탐지의 한계를 확인한 뒤, 사전 학습된 딥러닝 객체 탐지 모델 YOLO를 실행할 환경 준비.
- **직접 수행한 작업:**
  1. 기존 프로젝트의 `.venv` 가상환경 활성화
  2. `python -m pip install -U ultralytics` 실행
  3. YOLO/PyTorch import 및 MPS 사용 가능 여부 확인
- **관찰한 결과:**
  - `YOLO 설치 성공`
  - PyTorch 버전: `2.14.1`
  - `MPS 사용 가능: True`
  - Ultralytics 설정 파일 생성 안내가 출력됐으며 설치 오류는 발생하지 않음.
- **해석 및 한계:**
  - Ultralytics와 PyTorch를 현재 가상환경에서 불러올 수 있음.
  - MPS 사용 가능 여부가 True이므로 Apple Silicon GPU 가속을 사용할 수 있는 환경임. 실제 YOLO 추론이 MPS에서 정상 수행되는지는 다음 실행에서 확인해야 함.
  - 아직 카메라 입력, 탐지 정확도, FPS, 가림 상황의 성능은 검증하지 않음.
- **다음 단계:** 사전 학습된 경량 YOLO 모델을 Mac 내장 카메라(인덱스 1)에서 실행하고 클래스, confidence, bounding box를 표시한다.
